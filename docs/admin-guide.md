# Studio kısa kılavuz

`/studio/` adresinde yetkili Supabase hesabıyla giriş yapın. İçerik bölümünde taslak oluşturup dil/tür/durum seçin. Kategori ve etiketler ilgili bölümlerden eklenir. Yayınlama için durum `published` yapılır. Studio V1'in tüm gerekli ekranları henüz tamamlanmadığı için ayrıntılı kullanım akışı sonraki geliştirmeye bağlıdır.
